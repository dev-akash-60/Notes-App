
# 📝 Notes App

A simple and responsive Notes App built using React.js and Tailwind CSS. This application allows users to create, view, and delete notes with an attractive sticky-note design.

## 🚀 Features

- ➕ Add new notes with a title and description.
- 📋 Display all notes dynamically.
- 🗑️ Delete individual notes.
- ⚡ Real-time UI updates using React State.
- 🎨 Attractive sticky-note background design.
- 📱 Responsive layout using Tailwind CSS.
- ✨ Interactive buttons with hover and click effects.

## 🛠️ Technologies Used

- **React.js** – Building the user interface.
- **JavaScript (ES6+)** – Application logic.
- **Tailwind CSS** – Styling and responsive design.
- **Lucide React** – Icons.
- **Vite** – Development environment.

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/dev-akash-60/Notes-App.git
```

### 2. Navigate to the project folder

```bash
cd notes-app
```

### 3. Install dependencies

```bash
npm install
```

### 4. Install Lucide React

```bash
npm install lucide-react
```

### 5. Start the development server

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.

## 📸 How to Use

1. Enter a note heading.
2. Write the note details.
3. Click the **Add Note** button.
4. Your note will appear in the Recent Notes section.
5. Click the **Delete** button to remove a note.
